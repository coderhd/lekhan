---
title: Daily notes and quick capture
description: Capture something quickly and give it a permanent place when it is ready.
---

Choose **Today** in the local sidebar. Lekhan opens or creates a daily page with Notes and Tasks sections. Use it for meeting notes, reminders, and unfinished thoughts.

For a long-running inbox, create a page such as **Quick capture** and add it to Favorites. When a note has a clear topic, move it under that page or create a page link. Use **Page context** on the topic page to find the original references.

See [Pages](/docs/concepts/pages) and [Page links and backlinks](/docs/concepts/links-and-backlinks).

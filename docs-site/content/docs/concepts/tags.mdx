---
title: Tags
description: Find a topic across pages using inline tags and imported properties.
---

Add a tag such as `#research` to page text. Lekhan also reads supported tags from imported YAML frontmatter.

Use **Find a page** and search for `#research`. In the local workspace, related tags can also appear in **Page context**. In the cloud workspace, tags are indexed along with page text when changes sync.

Choose a tag you can recognize and reuse it across related pages. Use a page link when you want to refer to a specific note.

See [Page links and backlinks](/docs/concepts/links-and-backlinks) and [Import an Obsidian vault](/docs/getting-started/obsidian-import).

---
title: The page graph
description: Understand how the workspace connects pages, parent pages, links, and tags.
---

Lekhan connects each page to its parent, its outgoing links, and its tags. The same structure lets the workspace resolve imported links and lets search find pages by titles, tags, and linked targets.

In the local workspace, inspect connections in **Page context** and use **Find a page** to jump to a result. In the cloud workspace, search returns pages you own or that were shared with you.

Try writing one short page per topic, linking it from a project page, then opening the topic’s backlinks to see the references.

See [Page links and backlinks](/docs/concepts/links-and-backlinks) and [Tags](/docs/concepts/tags).

---
title: Page links and backlinks
description: Connect notes with wikilinks and use backlinks to find the pages that mention yours.
---

Type `[[` and start writing a title. Choose a result to insert the link. For exported Markdown, the link uses wikilink syntax such as `[[Research/Field notes|the field notes]]`.

In the local workspace, open **Page context → Backlinks** to see which pages link to the current one. On a cloud page, open **Backlinks** below the editor to see links from pages you have access to in your notebook. A heading anchor such as `[[Research/Field notes#Evidence]]` opens the named section when it resolves.

If two pages have the same title, include their parent path to choose a branch. Use a leading slash for a page at the top level, as in `[[/Field notes]]`. For an imported cloud note in source mode, open **Page links** below the source or choose **Preview Markdown** to follow links in the note.

See [The page graph](/docs/concepts/graph) or [Tags](/docs/concepts/tags).

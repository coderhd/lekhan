---
title: Page links and backlinks
description: Connect notes with wikilinks and use backlinks to find the pages that mention yours.
---

Type `[[` and start writing a title. Choose a result to insert the link. For exported Markdown, the link uses wikilink syntax such as `[[Research/Field notes|the field notes]]`.

In the local workspace, open **Page context → Backlinks** to see which pages link to the current one. Click a backlink to open the source. A heading anchor such as `[[Field guide#Make it yours]]` opens the named section when it resolves.

If two pages have the same title, use their folder path to be explicit. For an imported cloud note in source mode, open **Page links** below the source to follow a resolved link.

See [The page graph](/docs/concepts/graph) or [Tags](/docs/concepts/tags).

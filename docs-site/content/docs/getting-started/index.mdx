---
title: Write your first page
description: Start in your browser notebook, add a page, and connect it to another note.
---

Use **Open workspace** in the docs navigation to sign in and open Lekhan. Your workspace starts with a Field guide and example pages.

<Steps>
  <Step>
    Choose **New page** in the sidebar, enter a page title, and write a paragraph.
  </Step>
  <Step>
    Type `/` at the start of a block to insert headings, lists, callouts, and code blocks.
  </Step>
  <Step>
    Type `[[` and select a page such as **Field guide** to create a link. Open **Page context** to see backlinks to every source note.
  </Step>
  <Step>
    Press **⌘ K** on macOS or **Ctrl K** on Windows or Linux to jump to any page by title or body text.
  </Step>
  <Step>
    Confirm the save status in the footer and use **Export Markdown** in the page actions menu to download a standalone copy.
  </Step>
</Steps>

Open **Keyboard shortcuts** in the sidebar, or press **⌘ /** on macOS or **Ctrl /** on Windows or Linux. **Quick switch** matches page titles, while **Search pages** scans note bodies, tags, and links. In the sidebar page tree, move between visible notes with **↑** and **↓** and press **Enter** to open one.

<Callout type="info" title="Browser storage and backups">
  Local notebook edits save in the active browser profile. Export a Markdown file or workspace ZIP before clearing site data or moving devices.
</Callout>

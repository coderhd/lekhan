---
title: Write your first page
description: Start in the local workspace, add a page, and link it to another note.
---

Use **Open workspace** in the docs navigation to start Lekhan. The local workspace opens with a Field guide and a few example pages.

1. Choose **New page** in the sidebar. Give the page a name and write a paragraph.
2. Type `/` at the start of a block to find headings, lists, callouts, and other blocks.
3. Type `[[` and choose a page such as **Field guide**. Click the inserted link to follow it. Open **Page context** to return to the page that linked here.
4. Use **⌘ K** on macOS or **Ctrl K** on Windows or Linux to find a page by title or text. Press Enter to open it.
5. Check the save status and use **Export Markdown** in the page menu to keep a copy.

The local workspace saves in the current browser. If you use a different browser profile or clear site data, open a copy from your Markdown export.

See [Pages](/docs/concepts/pages), [Daily notes and quick capture](/docs/guides/daily-notes), or [Markdown import and export](/docs/getting-started/markdown-import-export).

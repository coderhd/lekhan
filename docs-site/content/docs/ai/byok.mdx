---
title: Use your own API key
description: Add a hosted AI provider and choose which information goes with each request.
---

1. In the local workspace, open **Writing assistant** and unlock or set up its passphrase.
2. Open **Providers** and choose a provider. Use the provider’s key link to open its account page.
3. Enter the key and your model ID. Choose **Test connection** to check the endpoint and discover models when the provider supports discovery.
4. Choose **Save connection**. Switch to **Ask**, choose the connection, and send a short prompt.
5. Use **Include this page with my request** only if the provider needs the page’s content.

Lekhan’s browser stores encrypted connection settings. The passphrase is needed to unlock them. Provider availability, retention, rates, and limits depend on the selected service and account.

For OpenAI-compatible services outside the supplied list, choose **OpenAI-compatible endpoint** and enter the API base URL. Include a version path such as `/v1` if the provider specifies it.

See [Free-key presets](/docs/ai/free-key-on-ramp) and [Troubleshooting](/docs/troubleshooting).

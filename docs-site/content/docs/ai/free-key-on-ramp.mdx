---
title: Free-key presets
description: Select a starting model, bring your own provider key, and check the current quota.
---

A preset fills in a provider and model ID. The provider supplies the key and decides whether the model is free or available for your account.

1. Open **Writing assistant → Providers** in the local workspace.
2. Choose a **Free-key preset**. The current list includes OpenRouter, Google Gemini, Groq, and Z.AI options.
3. Follow the provider link, create a key, and check the provider’s current model and quota details.
4. Paste your key, choose **Test connection**, and save it. Send a short request to verify generation.

If the preset is unavailable, pick a model listed for your account and enter its ID. Provider model names and free access can change.

- [OpenRouter free router](https://openrouter.ai/openrouter/free)
- [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing)
- [Groq model catalog](https://console.groq.com/docs/models)
- [Z.AI model guide](https://docs.z.ai/guides/llm/glm-4.7)

See [Use your own API key](/docs/ai/byok).

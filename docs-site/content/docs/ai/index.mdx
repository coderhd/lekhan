---
title: AI connections
description: Choose a hosted provider with your key or connect to a local inference server.
---

Open **Writing assistant** from the local workspace. Set a passphrase to protect saved connections, then unlock it when you return.

In **Settings → AI Providers & Models**, unlock the provider vault and open **Browse model presets**. Filter by cost, where the model runs, local download size, context window, or language support. **Use** fills a new connection with the provider and model ID. For Ollama, install that model before testing the connection.

- [Use your own API key](/docs/ai/byok) for a hosted provider.
- [Use a free-key preset](/docs/ai/free-key-on-ramp) if your provider account supports one.
- [Run AI with Ollama or LM Studio](/docs/ai/byol) to use a model on the same computer.

Lekhan sends the request directly to the selected connection. It sends the current page only when you enable **Include this page with my request**. Use **Insert in page** to add a response after reviewing it.

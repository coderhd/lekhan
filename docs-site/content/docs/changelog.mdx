## H0 rebuild

- Local writing, keyboard search, page context, Markdown export, and vault import.
- Cloud page editing, offline reconnection, invitations, public links, checkpoints, and resumable vault imports.
- Provider connections with optional page context, supported local inference endpoints, and available free-key presets.
- Localized marketing and account screens, along with a public page reader and early-access signup.

See the [repository history](https://github.com/coderhd/lekhan/commits/main/) for changes merged into the main branch.

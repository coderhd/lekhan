## Run the cloud writer

Set the app's Supabase URL and publishable key, `LEKHAN_PUBLIC_URL`, `LEKHAN_SYNC_URL` and `LEKHAN_SYNC_TICKET_SECRET`. The ticket endpoint also needs `SUPABASE_SECRET_KEY` on the server to check workspace entitlements. Use `ws://localhost:8080` for a local relay and a `wss://` origin for a hosted relay.

Start the relay with `npm run sync` on Node 24. Use the same app origin, Supabase configuration and ticket secret. Set `LEKHAN_ENCRYPTION_KEY` and mount a persistent directory at `LEKHAN_WAL_DIR`. Run a single writer per environment and keep the volume through relay restarts. During migration, keep the existing snapshot key available in `LEKHAN_ENCRYPTION_PREVIOUS_KEYS` as a comma-separated decrypt-only list. The relay exposes `/health` for readiness checks.

Provider-vault backup requires `20261124021014_rebuild_provider_vault_sync.sql` on the existing profile schema and a server-only Supabase secret key. Use explicit column lists for browser queries against `profiles`. The backup column is exposed to the service role through the authenticated Next.js route. Verify the profile clients in staging before applying the migration in production. [Supabase column privileges](https://supabase.com/docs/guides/database/postgres/column-level-security)

Page invitations require `20261121000000_rebuild_page_invitations.sql` after the existing Pages graph and billing migrations. Apply `20261123024120_rebuild_collaborator_admission.sql` after the existing sync ledger migration and release it with the rebuilt app and relay. Owners copy links from the share screen. The recipient's verified account email must match the invitation's address. The page membership holds the seat, and the ledger keeps attendance history when access is removed. [Supabase column privileges](https://supabase.com/docs/guides/database/postgres/column-level-security)

Deploy the relay before publishing the client that sends large sync updates in chunks. Ordinary sync messages keep the existing wire format. The relay limits incomplete transfers and queued bytes, and its page snapshot ceiling is 64 MiB. The web app hands large checkpoint uploads and checkpoint previews to the relay over HTTPS. Route `/checkpoint-transfer` to that same host and verify the deployed Storage object limit. Apply `20261123103638_rebuild_page_sync_preferences.sql` alongside the app and relay and forward `/page-sync/` to the relay for server-side preference changes. The relay checks the caller’s access and retention window again before serving a checkpoint.

The app and relay share `LEKHAN_ENCRYPTION_KEY` and the decrypt-only rotation keys. Apply `20261123023343_rebuild_checkpoint_retention.sql` before enabling cleanup. Vercel calls `/api/cron/retention-prune` daily at 05:30 UTC with `CRON_SECRET`. The optional relay flag `LEKHAN_PRUNE_CHECKPOINTS=1` uses the same claims at startup and every six hours. Manual staging runs can call the same route with a Bearer token. A failed Storage deletion leaves checkpoint metadata in place and its lease expires after ten minutes. [Vercel cron scheduling](https://vercel.com/docs/cron-jobs/manage-cron-jobs) · [Supabase Storage removal](https://supabase.com/docs/reference/javascript/storage-from-remove)

Cloud import requires `20261121000001_rebuild_cloud_import.sql` after the existing import ledger and graph-index migrations. Apply `20261123025136_rebuild_cloud_import_image_policy.sql` with the new import routes. Apply `20261123123806_rebuild_local_mirror_hierarchy.sql` before enabling the notebook importer. Apply `20261123124652_rebuild_paid_notebook_mirror.sql` with the app to enable paid automatic notebook sync. Untouched starter pages stay local unless they hold user content beneath them or the owner chooses to sync them. A reserved batch keeps its recorded policy. Reservations from before the new policy retain their original digest. `LEKHAN_PRUNE_IMPORT_RECEIPTS=1` retains 30 days of import receipts. The browser targets batches under 4 MiB when possible and sends larger individual notes separately. Check the deployed request limit for those notes. [Vercel Functions limits](https://vercel.com/docs/functions/limitations)

Apply `20261123100837_rebuild_documents_storage_capacity.sql` at the Storage write cutover because it restricts direct browser uploads to the `documents` bucket. The app and relay reserve capacity before creating or growing an object. Both use a 1 GB default ceiling. Set the same `LEKHAN_DOCUMENTS_STORAGE_LIMIT_BYTES` on both services if the hosted quota differs. When capacity stalls relay snapshots, the durable WAL retains accepted edits until the relay can flush them. [Supabase Storage metadata](https://supabase.com/docs/guides/platform/manage-your-usage/storage-size)

Apply `20261123101717_rebuild_cloud_attachments.sql` with the app and relay. Send HTTPS requests under `/attachments/` to the relay. The retention cron and optional relay retention worker also remove interrupted uploads, removed files, and files on deleted pages. Apply `20261123102727_rebuild_workspace_media_usage.sql` with the app and relay. Before enabling the new writers, flush and stop the previous relay and run `node --env-file-if-exists=.env.local --disable-warning=MODULE_TYPELESS_PACKAGE_JSON server/sync/backfill-media-usage.ts` against the target environment. The command reads existing snapshots and updates their usage records. Start the rebuilt relay after the backfill completes.

Early access requires `20261121000002_rebuild_waitlist.sql` and `LEKHAN_WAITLIST_RECEIPT_SECRET`. In a fresh staging database the migration installs the roster and outbox. In production it uses the existing position sequence and transfers app writes to service-role RPCs, so release it alongside the rebuilt waitlist routes. Set `BREVO_API_KEY`, `WAITLIST_CONFIRM_FROM`, and `BREVO_FOUNDING_LIST_ID` on the app and relay. Enable `LEKHAN_DRAIN_WAITLIST=1` on the relay for minute-by-minute retries. `NEXT_PUBLIC_GA4_ID` enables the optional consent control. [Brevo contact API](https://developers.brevo.com/reference/create-contact) · [Google basic consent mode](https://developers.google.com/tag-platform/security/guides/consent?consentmode=basic)
